# תגובה → הודעה פרטית

מישהו מגיב מילה מתחת לפוסט שלכם, ומקבל את הלינק בהודעה פרטית, אוטומטית.
זה מה ש-ManyChat עושה, וזה שלוש קריאות API.

באינסטגרם זאת הודעה פרטית אמיתית עם כפתורים. ביוטיוב זאת תגובה ציבורית, כי
ביוטיוב אין הודעות פרטיות בכלל. בטיקטוק זה לא אפשרי, לא כאן ולא בשום כלי אחר.

## מה צריך

- **Claude Code** על המחשב
- **חשבון Zernio** עם אינסטגרם מחובר
- **חשבון אינסטגרם עסקי או יוצר.** חשבון פרטי לא חושף תגובות ולא הודעות, ואין
  דרך לעקוף את זה
- **Python 3**, כבר מותקן בכל מק

## התקנה

מורידים את הקובץ, ואז אומרים לקלוד:

```
תתקין לי את הסקיל הזה
```

או לבד, שורה אחת:

```bash
unzip ~/Downloads/comment-to-dm.zip -d ~/.claude/skills/
```

אחר כך שמים את המפתח שלכם ליד הסקיל, ולא בתוך הקוד:

```bash
echo 'LATE_API_KEY=המפתח_שלכם' > ~/.claude/skills/comment-to-dm/.env
chmod 600 ~/.claude/skills/comment-to-dm/.env
```

ומעתיקים את קובץ ההגדרות:

```bash
cd ~/.claude/skills/comment-to-dm
cp config.example.json config.json
python3 scripts/keyword_dm.py accounts
```

הפקודה האחרונה מחזירה את המזהים של החשבונות שלכם. אל תקלידו אותם ביד, תעתיקו
משם. אם היא מחזירה שגיאה, המפתח לא תקין, ועדיף לגלות את זה עכשיו.

סוגרים את קלוד, פותחים מחדש, וזהו.

## מה עכשיו

`config.json` הוא המקום היחיד שבו יושב משהו אישי שלכם, והוא לא נכלל בגיט.
כל מה שנמצא ב-`config.example.json` הוא מציין מקום, כולל המילים והנוסח, ובכוונה:
הקמפיין הזה צריך להיות שלכם, לא העתק של מישהו אחר.

הדבר הכי שימושי שאפשר לעשות מכאן הוא לפתוח את הסקיל מול קלוד ולהגיד לו:

```
תקרא את SKILL.md ואת scripts/keyword_dm.py בתיקייה הזאת,
ותסביר לי מה כל תת-פקודה עושה.
אחר כך תעזור לי להגדיר קמפיין ראשון ב-config.json.
```

ההסבר המלא, כולל הנוסח שעובד והמלכודות שכדאי לדעת מראש, נמצא ב-`SKILL.md`
וב[מדריך המלא](https://explain.co.il/guides/replace-manychat-with-claude).

## אזהרה אחת שחשוב לקרוא

מה שסוגר חשבונות זה **דיווחי ספאם**, לא ה-API. כל עוד אתם עונים רק למי שכתב לכם
מילה מסוימת, אתם בצד הבטוח. ברגע שכלל תופס רחב מדי, אנשים שלא ביקשו כלום מקבלים
מכם הודעה, וזה בדיוק מה שמדווחים עליו.

תריצו `python3 scripts/keyword_dm.py audit` אחרי כל שינוי. הוא נכשל בדיוק על
הדברים שמסוכנים: מילות מפתח קצרות בהתאמה חלקית, כללים שתופסים את כל הפוסטים,
וקיצור לינקים בהודעות.

הסקיל בא כמו שהוא, בלי אחריות. אתם אחראים לשימוש ולכללי הפלטפורמה של כל חשבון
שתחברו אליו.
