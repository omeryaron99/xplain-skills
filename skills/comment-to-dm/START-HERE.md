# תגובה → הודעה פרטית

מישהו מגיב מילה מתחת לפוסט שלכם, ומקבל את הלינק בהודעה פרטית, אוטומטית.
זה מה ש-ManyChat עושה, וזה שלוש קריאות API.

באינסטגרם זאת הודעה פרטית אמיתית עם כפתורים. ביוטיוב זאת תגובה ציבורית, כי
ביוטיוב אין הודעות פרטיות בכלל. בטיקטוק זה לא אפשרי, לא כאן ולא בשום כלי אחר,
כולל ManyChat עצמה.

---

# תתחילו כאן

שני צעדים. אחר כך קלוד עושה את השאר.

## 1. להתקין

גוררים את הקובץ `comment-to-dm.zip` לחלון של Claude Code ואומרים לו:

```
תתקין לי את הסקיל הזה
```

מי שמעדיף לבד, שורה אחת בטרמינל:

```bash
unzip ~/Downloads/comment-to-dm.zip -d ~/.claude/skills/
```

סוגרים את קלוד ופותחים מחדש. זה הכרחי, הוא טוען סקילים רק בעלייה.

## 2. להדביק את הפרומפט הזה

```
תקרא את ~/.claude/skills/comment-to-dm/setup/INTERVIEW.md
ותעביר אותי את ההקמה שלב אחרי שלב.

שאלה אחת בכל פעם, בעברית.
אל תיצור שום דבר אמיתי מול ה-API לפני שאמרתי לך במפורש כן.
```

מכאן קלוד מראיין אתכם. הוא ישאל מה אתם מחלקים, איזו מילה אנשים יגיבו, לאן הלינק
מוביל, ומאיפה לקחת את המפתח. אתם עונים בעברית, הוא כותב את הקבצים, מריץ את בדיקות
הבטיחות, ומראה לכם הכל לפני שהוא מפעיל משהו.

**מה שאתם צריכים שיהיה מוכן לפני שאתם מתחילים:**

- חשבון Zernio עם אינסטגרם מחובר
- אינסטגרם **עסקי או יוצר**. חשבון פרטי לא חושף תגובות ולא הודעות, ואין דרך לעקוף
- מפתח API מההגדרות של Zernio
- הלינק שאתם רוצים לשלוח

## למה זה בטוח

מה שסוגר חשבונות זה **דיווחי ספאם**, לא ה-API. כל הקריאות כאן הן הרשמיות של Meta,
דרך המפתח שלכם. הסכנה היחידה היא לשלוח הודעה למישהו שלא ביקש כלום, ונגד זה יש כאן
שלוש שכבות:

1. **הראיון מסרב** להמשיך עם מילת מפתח שתתפוס תגובות תמימות, ויסביר למה.
2. **הכלל נצמד לפוסט אחד**, אף פעם לא לכל החשבון, כך שתגובה על פוסט מלפני שנתיים
   לא נשאבת פנימה.
3. **`audit`** רץ אחרי כל שינוי ונכשל בדיוק על הדברים המסוכנים.

אם קלוד מנסה לדלג על אחד מהשלושה, תעצרו אותו. הם שם בכוונה.

הסקיל בא כמו שהוא, בלי אחריות. אתם אחראים לשימוש ולכללי הפלטפורמה של כל חשבון
שתחברו אליו.
