# seedance-prompt, איך מתקינים

הסקיל הזה הופך תיאור פשוט של סרטון לפרומפט מלא ל-Seedance 2.5, כולל רשימת
הרפרנסים לפי סדר ההעלאה וההגדרות שצריך לבחור.

## התקנה, פעם אחת

1. פותחים את תיקיית הסקילים של Claude Code:

   - **Mac:** `~/.claude/skills/`
   - **Windows:** `C:\Users\<שם המשתמש>\.claude\skills\`

   אם התיקייה לא קיימת, יוצרים אותה.

2. גוררים לשם את התיקייה `seedance-prompt` כמו שהיא, עם כל מה שבתוכה.
   המבנה בסוף צריך להיראות ככה:

   ```
   .claude/skills/seedance-prompt/SKILL.md
   .claude/skills/seedance-prompt/reference/anatomy.md
   .claude/skills/seedance-prompt/reference/examples.md
   ```

3. פותחים Claude Code מחדש.

## איך משתמשים

פשוט מספרים לו מה אתם רוצים בסרטון:

```
תכתוב לי פרומפט ל-Seedance לסרטון של בחור שנוסע בפרארי אדומה
ברחוב רטוב בלילה. 15 שניות, אנכי, יש לי תמונה שלו ותמונה של הרכב.
```

או בקריאה ישירה:

```
/seedance-prompt סרטון מוצר של בקבוק זכוכית על אבן רטובה, 12 שניות, לרוחב
```

מה שחוזר: הפרומפט בבלוק אחד להעתקה, רשימת הרפרנסים לפי הסדר שצריך להעלות
אותם, ושורת ההגדרות, יחס, רזולוציה, אורך, ביטרייט ואודיו.

באהבה, מתן ועומר.
