# מחקר מתחרים באינסטגרם

הסקיל שאומר לכם מה לפרסם השבוע.

הוא אוסף את הפוסטים של השבוע האחרון מרשימת המתחרים שלכם, מדרג אותם לפי כמה כל
פוסט ״פרץ״ ביחס לרגיל של אותו יוצר, שולח סוכן נפרד לפרק כל פוסט מנצח (ההוק,
הפורמט, התמליל, ולמה זה עבד), ובונה דוח אחד עם גרסה שלכם לכל פוסט.

---

# תתחילו כאן

שני צעדים. אחר כך קלוד עושה את השאר.

## 1. להתקין

גוררים את הקובץ `ig-competitor-research.zip` לחלון של Claude Code ואומרים לו:

```
תתקין לי את הסקיל הזה
```

מי שמעדיף לבד, שורה אחת בטרמינל:

```bash
unzip ~/Downloads/ig-competitor-research.zip -d ~/.claude/skills/
```

סוגרים את קלוד ופותחים מחדש. זה הכרחי, הוא טוען סקילים רק בעלייה.

## 2. להדביק את הפרומפט הזה

```
תקרא את ~/.claude/skills/ig-competitor-research/setup/INTERVIEW.md
ותעביר אותי את ההקמה שלב אחרי שלב.

שאלה אחת בכל פעם, בעברית.
אל תריץ שום דבר שעולה כסף לפני שאמרתי לך במפורש כן.
```

מכאן קלוד מראיין אתכם. הוא יבדוק מה מותקן אצלכם, יעזור לכם להכניס את המפתח של
Apify בצורה בטוחה, ישאל מי אתם ואיזה מתחרים לבדוק, ויריץ איתכם את הדוח הראשון.

**מה שכדאי שיהיה מוכן לפני שמתחילים:**

- חשבון ב-[Apify](https://apify.com). החבילה החינמית מספיקה כדי להתחיל
- 5 עד 8 חשבונות אינסטגרם ציבוריים מהנישה שלכם, שמפרסמים כל שבוע
- משפט או שניים על עצמכם: מה אתם מלמדים או מוכרים, ומי צופה בכם

## מה עולה כסף

רק שלב אחד: האיסוף של הפוסטים דרך Apify. כל השאר, התמונות, התמלול והניתוח, רץ
אצלכם במחשב ובתוך Claude Code. קלוד יגיד לכם בדיוק מה הולך לרוץ לפני שהוא מריץ,
ויחכה לאישור שלכם.

## מה לא נמצא כאן

אין כאן שום מפתח, שום רשימת מתחרים ושום פרטים של אף אחד. הכל נכתב אצלכם, בקבצים
שלא יוצאים מהמחשב שלכם (`.env`, `config.json`, `competitors.md`).

הסקיל בא כמו שהוא, בלי אחריות. אתם אחראים לשימוש, לתנאים של Apify ולכללים של
אינסטגרם.
